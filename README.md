# Gemini AI Chatbot

## Project Description

Gemini AI Chatbot is a web-based application developed using HTML, CSS, and JavaScript. It integrates Google's Gemini API to provide AI-powered responses to user questions in real time.

The application provides a simple and user-friendly chat interface where users can interact with Gemini AI.

## Features

- AI-powered conversations using Google Gemini API.
- Real-time AI responses.
- User messages displayed on the right side.
- AI responses displayed on the left side.
- Modern and responsive user interface.
- API key configuration through settings.
- New chat functionality.
- Conversation history management.
- Error handling for API requests.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Fetch API
- Local Storage

## API Configuration

1. Visit Google AI Studio: https://aistudio.google.com/
2. Generate your Gemini API key.
3. Open the chatbot application.
4. Navigate to API Settings.
5. Enter your Gemini API key.
6. Click Save Key.

The application is now ready to use.

## How It Works

1. The user enters a question in the chat input field.
2. JavaScript captures the user's message.
3. The Fetch API sends the request to the Gemini API.
4. Gemini AI processes the question.
5. The generated response is received from the API.
6. The response is displayed in the chat interface.

## Security

- Do not upload your Gemini API key to GitHub.
- The current application stores the API key in browser Local Storage.
- For public deployment, use a backend server to protect your API key.
